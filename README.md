# Yandex Fuel Prices Card

Карточка Lovelace для интеграции **Yandex Fuel Prices** (`yandex_fuel_prices`) — цены на топливо на заправках из Яндекс Карт.

- сама находит все сенсоры цен интеграции (настраивать не обязательно);
- сортирует заправки по цене и отмечает **самую дешёвую**;
- у остальных показывает, **на сколько дороже** (`+13,00`), а в заголовке — разницу между заправками;
- **изменение цены**: ▲/▼ на сколько и когда цена менялась последний раз;
- **ступенчатый график** цен за N дней (долгосрочная статистика HA + точная история);
- время обновления цены в Яндекс Заправках, адрес, кнопка «открыть в Яндекс Картах»;
- значок `!`, если последнее обновление не удалось (показана последняя известная цена);
- клик по заправке открывает окно сенсора; визуальный редактор; светлая/тёмная тема; RU/EN.

## Установка через HACS

1. HACS → ⋮ → **Пользовательские репозитории** → URL этого репозитория, тип **Dashboard**.
2. Найдите **Yandex Fuel Prices Card** → Скачать. HACS сам добавит ресурс.
3. Обновите страницу браузера (Ctrl/Cmd + Shift + R).

### Вручную

Скопируйте `yandex-fuel-prices-card.js` в `/config/www/`, затем **Настройки → Панели → ⋮ → Ресурсы → Добавить**:
URL `/local/yandex-fuel-prices-card.js`, тип «JavaScript-модуль».

## Использование

Добавить карточку → **Yandex Fuel Prices Card**. Минимальная конфигурация:

```yaml
type: custom:yandex-fuel-prices-card
```

Все параметры:

```yaml
type: custom:yandex-fuel-prices-card
title: Пропан              # по умолчанию — название топлива
entities:                  # по умолчанию — все сенсоры цен интеграции
  - sensor.azs_lesnaia_propan
  - sensor.agzs_zarechnaia_propan
fuel: Пропан               # фильтр по топливу (без учёта регистра)
days: 30                   # период графика, дней
show_chart: true
show_trend: true           # ▲/▼ изменение цены
show_address: true
show_updated: true
sort: true                 # сортировать по цене
```

Если в карточке заправки с разным топливом, «самая дешёвая» и разница считаются отдельно для каждого топлива.
